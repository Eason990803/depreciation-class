小隊解密時間：回看我們的判斷

本教材比較的三種折舊方法

SL · 直線法

Dₜ = (C − S) ÷ n

每年分攤相同金額。

SYD · 年數合計法

Dₜ = (C − S) × (n − t + 1) ÷ [n(n + 1)/2]

剩餘年數包含本年；前期權數較高。

DDB · 雙倍餘額遞減法

初步折舊 = 期初帳面金額 × 2/n

Double-Declining-Balance Method。折舊不得使帳面金額低於殘值；已達殘值後為零。

C＝成本；S＝殘值；n＝耐用年限；t＝觀察年度；D＝當年折舊。所有金額以新臺幣元表示。殘值是以資產已達預期耐用年限終點的年齡與狀況，估計目前處分可取得、扣除處分成本後的金額；不是期末售價預測。

DDB 的本教材慣例：一般年度取「初步折舊」與「期初帳面金額 − 殘值」較小者；最後一年分攤全部剩餘可折舊額，不中途轉直線法。末年折舊可能回升，這是分攤慣例，並非四捨五入補差，也不是 IAS 16 指定的唯一演算法。
模型假設｜先理解比較的範圍

第 0 年股東投入等於設備成本的現金，隨即全數購入設備；購入後現金為 0、設備成本＝投入資本。第 1 年期初設備已達可供使用狀態，自該時起按完整年度折舊；本教材不處理部分年度。

每年營收與其他現金營業費用固定，全部當期收付；無營運資金變動、所得稅、利息、其他非營業損益、負債、股利或額外融資。折舊直接計入本期損益，期初保留盈餘為 0。為維持無融資模型，現金營業費用不得高於營收；仍可能因折舊產生淨損。

固定成本、殘值與年限，持有至年限終了；無減損、重估、估計變動、額外資本支出或處分，不另拆重大組成部分。末期殘值是保留的帳面金額，並不代表已賣出設備或收到現金。

04 / 從數字回到判斷

完成後複習：概念與準則

1. 當期：目前哪個方法淨利最高？為什麼？

2. 未來：某方法本年淨利較高，保留盈餘也一定較高嗎？

不一定。淨利取決於本年折舊；保留盈餘取決於截至本年的累計折舊。後期淨利排序即使反轉，先前累積的差額可能仍未消失。比較「當期」兩張表，再看剩餘可折舊額。

3. 全期：末期相同的是哪些數字？現金為什麼不變？

相同的是全期累計折舊、末期帳面金額、累計淨利與末期權益；末年折舊、末年淨利不必相同。現金相同源自本模型無稅且收付款安排固定；設備購入已在第 0 年支付現金。

4. 管理誘因：為了提高今年淨利，就能選擇該方法嗎？

不可以只為達成目標盈餘而選方法。IAS 16.60–62 要求方法反映資產未來經濟效益的預期耗用型態，並一致適用；至少每個財務年度終了檢視，耗用型態重大改變時相應調整，作為會計估計變動處理。IAS 16.62A 不接受以營收為基礎的折舊方法；本頁營收只用於損益與現金流模擬，不參與折舊額計算。這些預設情境沒有耗用型態資料，不能據此判定哪一方法最適合實際設備。

IFRS 方法選擇限制：本頁三種方法是教材的比較選項，不是 IFRS 的完整或指定清單。IAS 16.62 舉例為直線法、餘額遞減法及生產單位法；年數合計法是此處另選的加速分攤示例。
進階說明｜估計、組成部分與精度

IAS 16.51 要求至少每年末檢視殘值與年限；16.43 涉及重大組成部分分別折舊；16.48–49 下，折舊也可能先計入其他資產成本（例如存貨）。本頁為聚焦比較而省略這些情境。殘值高於帳面金額時折舊可為零（16.54）；本教材的 S ≤ C 是操作範圍限制，不是對所有實務情況的規定。

full precision 指保留 JavaScript Number 的未取整計算值，並非任意精度。相等判斷使用 |a−b| ≤ 10⁻⁸ + 10⁻¹² × max(|a|,|b|)，遠小於顯示的 1 元。期末累計折舊僅在數值容差內正規化為可折舊總額，以消除浮點殘差，不改動任何年度折舊。六位小數也只是預覽；CSV 分列原始計算值與整元顯示值，負值保留為數字。
